# 语言与语法

## 核心原则

> _"简洁胜于机巧，清晰胜于巧妙。"_

1. **代码是写给人看的**，机器能读懂是顺带的
2. **一致性至上**——风格统一比个人喜好更重要
3. **用最简单的方式**表达最清晰的意图

## 具体规则

1. 除插件类脚本可以使用 JavaScript，其他脚本强制使用 TypeScript。
2. 代码需符合 [ESLint](../eslint.config.mjs) + [Prettier](../.prettierrc) 规范。
3. 永远使用 const / let 来声明变量，绝不使用 var。
4. 使用命名函数声明；在能用箭头函数的地方，避免不必要的 function 关键字。
5. 参数不超过 4 个，多的用对象封装。
6. 优先使用严格比较（=== 和 !===）。
7. 使用 for...of 遍历数组；使用 for...in 遍历对象。
8. 类、函数注释使用 JSDoc 风格。
9. 严格基于 Cocos Creator 3.8+ 官方文档，如无特别说明，禁止使用已废弃 API。
10. 组件必须正确使用 onLoad(), start(), update(dt), onLateUpdate(dt), onEnable(), onDisable(), onDestroy() 等生命周期钩子。
