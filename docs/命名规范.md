# 命名规范

## 核心原则

> _"名字应该揭示意图，而非隐藏意图。"_

1. **见名知意** — 好的名字不需要注释解释
2. **一致即正义** — 同类事物用同一种命名风格
3. **避免缩写** — 除非是公认的缩写（如 HP、MP、URL）
4. **读音自然** — 名字应该易于朗读和记忆

## 具体规则

- 所有目录、资源与脚本文件强制使用 kebab-case 风格。
- 组件/类用 PascalCase，静态类/命名空间方法用 PascalCase，属性/方法用 camelCase，常量用 UPPER_SNAKE_CASE。

## 动词选择

| 动词             | 用途               |
| ---------------- | ------------------ |
| `get`            | 获取值（无副作用） |
| `set`            | 设置值             |
| `is/has/can`     | 返回布尔值         |
| `create`         | 创建新对象         |
| `init`           | 初始化             |
| `start`          | 启动流程           |
| `stop`           | 停止流程           |
| `update`         | 更新状态           |
| `render`         | 渲染显示           |
| `handle/process` | 处理数据或事件     |
